DST vs. PES Format: What Actually Changes During Conversion?

Both DST and PES are machine stitch files (coordinates in 0.1 mm steps), so your stitch density and needle path stay 100% identical—only the wrapper and machine metadata change.

Feature Tajima .DST Brother .PES (with PEC)
Primary Machines Tajima, Barudan, Ricoma, SWF, commercial multi-needle Brother (PE800, SE600, Innov-is, PR series), Baby Lock
Thread Color Storage No RGB/thread data (only color-stop flags) Stores Brother 64-color PEC palette indices per block
Max Single Move 12.1 mm (121 units) ternary encoding 204.7 mm (2,047 units) 12-bit long-form encoding
Machine LCD Preview None (no embedded thumbnail) 48 × 38 px monochrome composite & per-color icons
Trim Commands Usually simulated with 3 consecutive jumps Native PEC trim/jump flags (0x20 / 0x10)

Pre-Stitch Checklist for Brother Machines

  • Verify Hoop Clearance: Always match the hoop dropdown above to your physical frame (e.g. 100×100 mm for PE535/SE600, 130×180 mm for PE800/PE900).
  • Keep Auto-Center Enabled: Commercial .dst files sometimes start off-center. Auto-Center aligns the design center to (0,0) for Brother hoops.
  • Run the Stitch Simulator: Scrub the Play slider to catch long jump stitches or stray needle drops before wasting stabilizer and fabric.
  • USB Folder Tip: Copy the converted .pes file to the root of a FAT32 USB drive (under 32 GB works best on older Brother models) and avoid special characters in filenames.

Why Do DST Designs Open With Weird Colors?

Unlike .pes or .jef, the Tajima .dst format was invented for commercial multi-needle machines where operators manually assign cones to needles on the control panel. Because a .dst file contains zero color bytes, converters normally assign placeholder colors.

Using our Brother Thread Color Mapper above, you can map each color stop to an official Brother palette thread (like Prussian Blue #007, Red #800, Deep Gold #214, or Black #900) so your Brother screen shows accurate color steps immediately.

Frequently Asked Questions

Are my embroidery designs uploaded to any server?

No. This converter runs 100% inside your browser using JavaScript TypedArrays (Uint8Array & DataView). Even if you disconnect from the internet after loading the page, the converter continues working.

Will the converted .PES file work on Brother PE800, SE600, SE1900, and Baby Lock machines?

Yes. The exporter writes a clean #PES0001 container with a fully spec-compliant PEC machine block (including Brother 64-color palette indices, 12-bit jump/trim encoding, and 48×38 machine LCD thumbnails). Make sure the design dimensions fit inside your machine's maximum hoop.

Does converting DST to PES change stitch density or resize the design?

No. This tool performs a lossless stitch-coordinate translation from DST's 0.1 mm ternary records to PEC's 0.1 mm binary stream. Every stitch position and stitch count remains accurate without automatic re-digitizing.

Why is there a 256-color limit in PES/PEC files?

Brother's PEC header stores the number of color changes in a single unsigned byte (0–255), allowing up to 256 color blocks per file—more than enough for virtually all machine embroidery designs.
